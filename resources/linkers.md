# Thrust Compiler - Linker Resources

<img src="https://github.com/thrustlang/.github/blob/main/assets/standard-text-separator.png" alt="standard-separator" style="width: 1hv;">

Recurring resources for properly developing the linker integration of the compiler for different platforms.

- [LLD man page](https://man.archlinux.org/man/extra/lld/ld.lld.1) — Man page for LLD, the LLVM-based linker.
- [MSVC Linker Options](https://learn.microsoft.com/en-us/cpp/build/reference/linker-options?view=msvc-170) — Microsoft linker (link.exe) reference documentation.
- [ld64 man page](https://www.manpagez.com/man/1/ld64/) — Man page for ld64, the macOS linker.
- [LLD WebAssembly](https://lld.llvm.org/WebAssembly.html) — LLD WebAssembly backend documentation.
- [GNU ld man page](https://linux.die.net/man/1/ld) — Man page for GNU ld, the GNU linker.
