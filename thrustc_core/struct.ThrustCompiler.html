Fields§

§linked_objects: Vec<PathBuf>

Archivos objeto listos para ser enlazados, en orden de compilación.

§unready: &'thrustc [CompilationUnit]§source_to_object: HashMap<PathBuf, PathBuf>

Ruta del archivo fuente -> ruta del archivo objeto generado. Índice de deduplicación: cuando se reprocesa una unidad (p. ej., un módulo recompilado tras quedar pendientes instanciaciones genéricas), su archivo objeto anterior se reemplaza para que el enlazador no encuentre símbolos duplicados.
